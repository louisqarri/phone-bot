📱 PhoneBot

📖 README

PhoneBot is a small web page where you can look up the specifications of a smartphone, or compare two phones side by side. Pick the phone or phones from the lists, press the button, and the result appears on the page.

What it shows: release year, display, battery, cameras, storage, chipset and a short note for each phone.

Please note: the data is not up to date. It was collected for a limited list of phones, and prices, models and specs can change. Use it for fun, not for buying decisions.

About the project: PhoneBot is a personal learning project. It is not connected to any phone brand or store.

Built with:

  • Python
  • Flask (the web part)
  • SQLite with SQLAlchemy (the database)
